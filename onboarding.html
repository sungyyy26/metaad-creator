Meta Ads Duplicator 온보딩
(로컬 데스크탑)

Ad Duplication Desk 대시보드를 자기 컴퓨터에서 그대로 쓰고 싶은 팀원을 위한 안내서입니다. Claude 세션 없이 Meta API·Shopify API를 직접 호출하는 로컬 프로그램이라, 한 번 설치해두면 이후로는 계속 혼자 실행할 수 있습니다.

클로드에게 줄 프롬프트 1. 프로그램 설치 2. 코드 받기 3. 접속 정보 설정 4. 실행 5. 사용법

시작 전 체크리스트

  • 이 GitHub 저장소(sungyyy26/metaad-creator)에 접근 권한이 있는지 확인 — 없다면 저장소 관리자에게 미리 요청해두세요
  • 기존 사용자에게 META_ACCESS_TOKEN, SHOPIFY_SHOP, SHOPIFY_ACCESS_TOKEN 전달을 요청 (1:1로 안전하게 — 아래 STEP 3 참고)
  • Git·Python이 이미 설치되어 있는지 모른다면 그냥 진행하세요 — 아래 프롬프트가 확인부터 안내합니다

① 팀원 본인 Claude에게 그대로 붙여넣을 프롬프트

Claude Code(터미널이든 웹이든)를 열고 아래 문단을 그대로 붙여넣으세요. 프로그래밍을 몰라도 클로드가 한 단계씩 직접 설치·설정을 도와줍니다.

저장소 https://github.com/sungyyy26/metaad-creator 의 claude/wizardly-noether-2g3g1a 브랜치를 내 컴퓨터에 clone해줘. 이건 Meta 광고 세트/광고를 복제해서 만들어주는 로컬 대시보드야 (Flask 앱, webapp/app.py). 아래 순서로 나를 처음부터 끝까지 안내해줘: 1) Git, Python이 설치되어 있는지 확인하고, 없으면 설치 방법부터 알려줘. 2) 저장소를 clone하고 해당 브랜치로 전환한 뒤, pip install -r webapp/requirements.txt를 실행해줘. 3) .env 파일을 만들어야 하는데 (cp .env.example .env), 필요한 값(META_ACCESS_TOKEN, SHOPIFY_SHOP, SHOPIFY_ACCESS_TOKEN)은 내가 팀원에게 전달받아서 붙여넣을 거야. 어떤 값을 어디에 넣어야 하는지 알려줘. 4) python webapp/app.py로 서버를 실행하고, http://127.0.0.1:5000 에서 대시보드가 뜨는지까지 같이 확인해줘. 나는 프로그래밍을 잘 몰라. 명령어는 한 번에 하나씩 알려주고, 내가 결과(터미널 출력이나 화면 캡처)를 보여주면 그걸 보고 다음 단계로 안내해줘. 오류가 나면 원인을 짐작해서 알려주고 고쳐줘.
참고 같은 Meta 광고 계정·Shopify 스토어 권한이 있는 팀원이라면, 새 앱을 또 만들 필요 없이 이미 만들어둔 앱의 토큰을 그대로 전달받아 쓰는 게 훨씬 빠릅니다. 아래 가이드는 이 방법을 기준으로 합니다.

STEP 1Git · Python 설치

코드를 내려받고 실행하려면 두 프로그램이 필요합니다. 이미 설치되어 있다면 건너뛰세요.

  1. Python — python.org에서 최신 버전을 내려받아 설치. Windows라면 설치 화면에서 "Add python.exe to PATH" 체크박스를 꼭 체크하세요.
  2. Git — git-scm.com에서 설치. 설치 후 시작 메뉴에서 "Git Bash"를 찾아 여세요 — 이후 모든 명령어는 이 창에서 입력합니다.

STEP 2코드 받기

Git Bash를 열고 코드를 저장할 폴더로 이동한 뒤 내려받습니다.

cd ~/Documents
git clone https://github.com/sungyyy26/metaad-creator.git
cd metaad-creator
git checkout claude/wizardly-noether-2g3g1a
주의사항 git clone 실행 시 GitHub 로그인 창이 뜨면, 이 저장소에 접근 권한이 있는 계정으로 로그인하세요. "Repository not found" 오류가 나면 저장소 소유자에게 GitHub 접근 권한을 먼저 요청해야 합니다.

STEP 3접속 정보(.env) 설정

먼저 기존에 이 도구를 쓰던 팀원에게 아래 값을 안전한 방법(1:1 메시지, 비밀번호 관리자 등)으로 전달받으세요.

키설명
META_ACCESS_TOKENMeta Graph API 액세스 토큰 (광고 세트/광고 생성 권한)
SHOPIFY_SHOP스토어의 *.myshopify.com 도메인 (예: eqqualberry.myshopify.com)
SHOPIFY_ACCESS_TOKENShopify 커스텀 앱의 Admin API 액세스 토큰 (브릿지 페이지 생성용)
SHOPIFY_STOREFRONT_DOMAIN선택 — 커스텀 도메인 사용 시만 (예: eqqualberryglobal.com)
주의사항 이 값들은 광고 계정·스토어 관리자 권한과 동일합니다. 단체 채팅방이나 공개 채널에 올리지 말고, 반드시 1:1로 안전하게 전달하세요.

전달받았다면 Git Bash에서 .env 파일을 만듭니다.

cp .env.example .env
notepad .env

메모장이 열리면 아래처럼 전달받은 값으로 채우고 저장합니다.

META_ACCESS_TOKEN=전달받은_메타_토큰
SHOPIFY_SHOP=eqqualberry.myshopify.com
SHOPIFY_ACCESS_TOKEN=전달받은_Shopify_토큰
참고 .env 파일은 git에 올라가지 않도록 이미 설정되어 있습니다 (.gitignore). 컴퓨터를 바꾸거나 새로 clone할 때마다 이 파일만 다시 만들면 됩니다.

STEP 4실행

pip install -r webapp/requirements.txt
python webapp/app.py

Running on http://127.0.0.1:5000 메시지가 보이면 브라우저에서 http://127.0.0.1:5000 을 엽니다.

주의사항 .env는 서버가 시작될 때만 읽습니다. 값을 고치면 Ctrl+C로 멈추고 python webapp/app.py를 다시 실행해야 반영됩니다. 이후로는 이 창을 열고 이 두 줄만 실행하면 됩니다 — export는 다시 안 해도 됩니다.

STEP 5사용법

화면 우측 상단의 광고 셋팅 / 예산 조정 토글로 두 작업 영역을 오갑니다. 광고 셋팅은 세 개의 하위 탭으로 나뉘고, 예산 조정은 그 자체로 하나의 화면입니다.

대량 업로드

스프레드시트 행을 탭으로 구분해 붙여넣고 한 번에 여러 광고를 생성. 기본 탭입니다. "행 미리보기"로 실행 전에 각 행이 어떻게 파싱됐는지 먼저 확인할 수 있습니다.

수동 입력

광고 1건을 폼으로 채워 생성. 광고 계정은 캠페인에서 자동 감지되며, 직접 지정도 가능합니다.

소재 업로드

내 컴퓨터의 영상/이미지를 광고 계정의 소재 라이브러리에 바로 업로드 (공개 URL 불필요).

위 세 개는 광고 셋팅 모드의 하위 탭입니다. 예산 조정은 토글로 전환하면 나오는 별도 화면입니다:

예산 조정

채널·제품군으로 캠페인을 찾고, 엑셀/CSV 파일의 소재명을 그 안에서 매칭해 예산을 반영. 조회 결과를 확인하고 선택한 항목만 실제로 반영합니다.

대량 업로드 — 열 순서 (17개)

한 줄에 광고 1건, 열은 Tab으로 구분합니다.

#열비고
1캠페인필수 — 이름 또는 ID
2복제할 광고 세트비우면 광고만 기존 세트에 추가
3새 광고 세트 이름필수
4새 광고 이름필수
5일일 예산필수
6웹사이트 URL필수
7소재필수 — 라이브러리 파일명 일부
8헤드라인실제 문구 (자동 생성 미지원)
9기본 텍스트실제 문구 (자동 생성 미지원)
10시작비우면 즉시 — 2026/09/08 12AM 형식
11종료비우면 없음
12생성 후 상태비우면 일시중지
13Shopify 핸들선택 — 비우면 브릿지 페이지 없음
14Shopify 제목 재지정선택
15Shopify 태그 재지정선택, 쉼표 구분
16Shopify 템플릿 재지정선택
17Shopify 아마존 링크 재지정선택
주의사항 헤드라인·기본 텍스트에 "생성"이라고 입력하면 오류로 거부됩니다 — 이 로컬 도구는 Claude를 호출하지 않아 자동 카피 작성을 지원하지 않습니다. 실제 문구를 직접 써서 넣으세요.
참고 한 번에 너무 많은 행(수십 줄)을 넣으면 Meta 쪽 요청 제한에 걸릴 수 있습니다. 10~15줄 단위로 나눠 넣는 걸 권장합니다 — 걸리더라도 자동으로 재시도합니다.

요청 기록 카드 보는 법 & 삭제

각 카드는 상태 배지 · 제출 시각 · 일일 예산이 한 줄에 표시되고, 그 아래 C:(캠페인) · AS:(광고 세트) · AD:(광고 이름) 라벨로 구분됩니다. 카드 우측 상단의 × 버튼은 그 기록 하나만 지우고, 패널 제목 옆의 "전체 삭제" 버튼은 요청 기록 전체를 한 번에 지웁니다 — 어느 쪽이든 이 로컬 기록만 지울 뿐, 이미 Meta·Shopify에 만들어진 광고나 페이지는 그대로 남습니다.

행 미리보기 & 재시도

붙여넣은 뒤 "행 미리보기" 버튼을 누르면, 실제로 Meta에 요청을 보내기 전에 각 행이 어떤 광고 세트·광고로 파싱됐는지와 열 개수·형식 오류를 먼저 확인할 수 있습니다. 문제가 없는지 확인한 다음 "전체 행 실행"으로 넘어가세요.

요청 기록에서 오류로 표시된 항목에는 "재시도" 버튼이 함께 뜹니다 — 값을 다시 입력할 필요 없이 그 자리에서 같은 내용으로 재실행됩니다. (Meta 광고는 만들어졌지만 Shopify 페이지만 실패한 미완료 항목은 재시도 대상이 아닙니다 — 다시 실행하면 광고가 중복 생성되기 때문입니다. 이 경우는 화면에 뜬 Shopify 오류 메시지를 보고 직접 확인해주세요.)

라이트 / 다크 모드

화면 우측 상단의 동그란 버튼으로 라이트·다크 모드를 직접 전환할 수 있습니다. 아무것도 누르지 않으면 컴퓨터의 시스템 설정을 그대로 따라가고, 한 번 전환하면 그 선택이 이 브라우저에 저장되어 다음에 열 때도 유지됩니다.

예산 조정 탭 사용법

채널(Amazon/Boots — 목록의 "+ 새 채널 추가"로 직접 입력해 추가할 수도 있고, 한 번 추가하면 이 브라우저에 저장되어 다음에 열 때도 남아있습니다)과 제품군(예: v-srm, n-srm처럼 자유 입력, 비워두면 채널만으로 검색)을 정하고 예산 파일을 올린 뒤 조회를 누르면, 그 키워드를 모두 포함하는 이름의 캠페인들을 먼저 찾고, 그 캠페인들 안에서만 파일의 소재명과 일치하는 광고를 찾습니다. 예산은 항상 그 광고가 속한 광고 세트 단위로 바뀝니다 — 같은 광고 세트에 파일에서 값을 준 소재가 여러 개 있으면 (같은 값이어야 정상) 자동으로 하나로 합쳐서 보여주고, 만약 서로 다른 값이 들어있다면 어느 쪽이 맞는지 판단하지 않고 "값 충돌"로 따로 표시하니 파일을 확인해 다시 조회해주세요. 결과에는 Meta에 실제로 저장된 현재 예산과 파일이 말하는 기존 예산이 다를 경우에도 경고가 함께 뜹니다.

파일의 헤더 이름은 정확히 맞출 필요 없습니다 — 다음 중 하나로만 인식되면 됩니다:

  • 소재명: 소재, 소재명, 광고명
  • 기존 예산: 기존, 기존예산, 현재, 현재예산
  • 변경 예산: 변경, 변경예산, 제안, 제안예산
주의사항 조회 결과("2단계 · 결과 확인 및 반영")는 미리보기일 뿐, 체크박스로 선택한 항목만 우측 하단의 "적용" 버튼을 눌러야 실제로 Meta 예산이 바뀝니다 — 반영 전에 현재→변경 값을 꼭 확인하세요. .xls(옛 엑셀 형식)는 지원하지 않으니 .xlsx로 저장해서 올려주세요.
