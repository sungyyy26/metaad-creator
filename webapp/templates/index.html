새 광고 요청

달라지는 부분만 입력하세요 — 나머지는 복제할 광고 세트에서 그대로 가져옵니다.

소스
캠페인 이름을 그대로 입력해도 되고, 숫자 ID를 알면 그걸 써도 됩니다. 어느 광고 계정에 속해있는지는 자동으로 찾습니다 — 아래 "광고 계정"에서 직접 지정할 수도 있어요.
비워두면 새 세트를 만드는 대신, 아래 "새 광고 세트 이름"에 적은 이름의 (이미 있는) 광고 세트에 광고만 추가합니다.

광고
실제 문구를 입력하거나, 위 "소재"가 EQQUALBERRY 소재명 규칙(예: n-srm_ao_da_ig_fface-wrnk-timerewind_ksh_20260916-1)을 따르면 "생성"이라고 입력해 자동으로 채울 수 있습니다.
헤드라인과 마찬가지로 "생성"이라고 입력하면 소재명 기준으로 자동 작성됩니다.
고급 설정
광고는 생성 즉시 활성화됩니다. 다만 새로 만들어지는 광고 세트는 항상 일시중지 상태로 생성되어, 광고 세트를 직접 켜기 전까지는 실제로 노출되지 않습니다 (안전장치).
Shopify 브릿지 페이지 (선택)

복제할 상품의 핸들을 비워두면 브릿지 페이지를 만들지 않습니다. 새 페이지의 URL 핸들은 위의 "새 광고 이름"과 자동으로 동일하게 설정됩니다.

선택된 파일 없음
헤더 이름은 자유롭게 써도 됩니다 — 소재/소재명/광고명, 기존/기존예산/현재/현재예산, 변경/변경예산/제안/제안예산 중 하나로만 인식되면 됩니다.
